# 一口轻食 Web 前端设计规范（DESIGN-WEB）

> 状态：**M1 提案版** —— 三个候选方向待用户选定，选定后本文扩展为唯一规范（token 冻结）。
> 方法论：`.zcode/skills/frontend-design`（anthropics，Apache-2.0）+ 参考 `design/references/{linear,vercel}-DESIGN.md`。

## 0. 产品设定（brief）

- **产品**：一口轻食——轻食店运营者的外卖订单自动处理台（Excel 排单 + 平台自动下单 + 运行监控）。
- **用户**：店长/运营，每天重复使用的操作员工具；频率高、时长短、容错低。
- **界面使命**：配置任务 → 启动 → 盯日志 → 收到结果。信息密度与可扫读性优先于装饰。
- **气质锚点**（从主题世界取材）：餐饮订单的**单据/排单/备餐**语境；厨房的**干净、耐用、一目了然**。
- **硬约束**：双主题（浅色默认 + 深色可切换）；中文主文案；全部功能与旧版对齐（见 gui 功能对照表）；对比度 ≥ WCAG AA。

## 2. 三个候选方向

> 每个方向 = 色板（4–6 命名值）+ 字体角色 + 形状/层次 + **一个记忆点**（boldness 只花在一处）+ 深色映射。高保真 mock 见 `design/mocks/`。

---

### 方向 A「全麦 Wholegrain」— 暖棕木质操作台

从全麦面包/砧板/牛皮纸袋的世界取色。整个界面是一块干净的木质案板，表单是案上的餐卡。

- **色板（浅色）**：
  - 全麦棕 `#7A5A3A` —— primary：主按钮、选中态、focus 环
  - 面粉白 `#FAF7F1` —— canvas（暖而不奶油，刻意避开 #F4F1EA tell 区）
  - 瓷盘白 `#FFFFFF` —— 卡片 surface
  - 麸皮浅 `#EFE8DD` —— 次级面/输入底
  - 油墨深褐 `#2A241C` —— 正文（非纯黑）
  - 生菜绿 `#3E7C4F` —— 仅语义「成功」；危险 `#C0442E`（番茄红）；警示 `#C88A16`
- **字体**：正文/标题同族中文黑体系（MiSans → HarmonyOS Sans SC → Noto Sans SC），标题 600/-0.4px；数字（订单数、时间戳）用 mono tabular。无衬线 display——把衬线让给方向 C。
- **形状/层次**：卡 10px、输入 6px、按钮 8px（刻意不用旧版全胶囊）；轻阴影仅悬浮层，其余靠 1px 边框 + 底色阶。
- **记忆点**：主操作条的「开始处理」是全界面唯一的大面积全麦棕，且表单区上方挂一条 4px 全麦色顶线（像案板包边）——整页的暖色集中于此。
- **深色映射**：烤面包底 `#1D1710`、面板 `#262019`、文字 `#F3EDE3`、全麦棕提亮为 `#A67B4F`。
- **自审**：暖白底有滑向「cream tell」的风险——差异点在：accent 是棕不是赤陶、无衬线 display、无 hero 结构（工具页）。mock 里保持低暖度。

### 方向 B「冷链 Cold Chain」— 清晨厨房的设备屏

从不锈钢台面/冷链温度计/厨房 LED 屏取色。界面像一台擦亮的不锈钢设备：冷静、精确、卫生。

- **色板（浅色）**：
  - 钢青 `#2F7E8F` —— primary：主按钮、选中态
  - 凌晨灰 `#F4F7F8` —— canvas（冷调，无暖味）
  - 瓷白 `#FFFFFF` —— surface
  - 发丝线 `#E3E9EB` —— 边框（Vercel 式 hairline 体系）
  - 墨青黑 `#111C1F` —— 正文
  - 语义：成功 `#2E9E63`、危险 `#D5443C`、警示 `#E8A13C`（三色只做语义，不进装饰）
- **字体**：同族黑体系；**全部数字 tabular-mono**；标题 600/-0.5px。
- **形状/层次**：小圆角（输入 6px、卡 10px）；深色模式用 Linear 式「surface 阶梯」代替阴影。
- **记忆点**：日志控制台是一块「设备屏」——状态徽章做成 LED 点阵样式（running 时呼吸），每行日志带等宽行号与时间戳，运行中在控制台顶部有一条 2px 钢青进度微光。
- **深色映射**：深水底 `#0B1416`、面板 `#13202448` 阶梯、冰青强调 `#4FC3D8`。
- **自审**：低饱和冷灰是最容易滑向「任何仪表盘」的默认——差异点全押在设备屏日志与 LED 徽章上；若 mock 里这两处不出彩，此方向淘汰。

### 方向 C「早市 Morning Press」— 订单小票与印章

从中式早市/外卖小票/价签印刷取材。界面是一张摊开的干净单据：正文是铅字，日志是一台正在打印的小票。

- **色板（浅色）**：
  - 油墨黑 `#1B1B18` —— primary：主按钮（Vercel 式黑钮）、标题文字
  - 票纸白 `#F7F4EC` —— canvas
  - 白卡 `#FFFFFF` —— surface
  - 朱砂 `#C2402A` —— **仅**品牌时刻：Logo 章、选中 tab 标记、状态徽章点（稀缺使用）
  - 价签黄 `#F2DC9B` —— 仅日志搜索命中高亮（沿用旧 #fff2a8 语义）
  - 语义：成功 `#38764C`、危险 `#9E2B25`（砖红，与朱砂拉开明度）、警示 `#A66A0A`
- **字体**：**双族明确分工**——标题/大数字用宋体系（Noto Serif SC 600，印刷铅字感）；表单正文用黑体系；**日志区整段等宽**（JetBrains Mono → Noto Sans Mono CJK SC），像真实小票。
- **形状/层次**：直角倾向——输入 4px、按钮 6px、卡 8px、徽章 2px；边框 1px 油墨 12% 透明度；无阴影（印刷品是平的）。
- **记忆点**：**日志控制台 = 一张正在打印的小票**：顶部锯齿边（CSS mask）、条目间虚线裁切线、等宽时间戳、底部一条打印基线。全页的戏剧性只在此处。
- **深色映射**：夜市墨 `#16150F`、票纸变深牛皮 `#211E15`、朱砂提亮 `#E06A50`、文字 `#EFEAD8`。
- **自审**：等宽小字是 slop tell 清单项——但此处等宽承担真实信息编码（小票/时间戳），且仅限日志区，不外溢到表单。虚线分隔有票据出处，非装饰性 hairline。风险：宋体标题在小字号发虚——只用于 ≥18px。

## 3. 三方向共同的纪律（选定后并入规范正文）

- 状态色永不做装饰；primary 只出现在主按钮/选中态/焦点环。
- 表单 helper 文案：默认隐藏，聚焦或出错时出现（降噪，替代旧版常驻 helper）。
- 错误不道歉、不含糊；Toast + 日志双通道。
- 动效只响应用户动作（开合、确认、开始/停止）；running 徽章呼吸是唯一常驻动效；`prefers-reduced-motion` 全降级。
- 焦点环永远可见；触达目标 ≥ 36px（桌面）。
- 圆角、间距、字号只从 token 取；新组件先加 token 再用。

## 4. 决策记录

- [x] 双主题：浅色默认，深色一键切换，token 同源（用户选定）
- [x] 视觉：全新提案，不受旧绿色约束（用户选定）
- [x] 旧 UI：验收后删除（用户选定）
- [x] 方向：**「全麦早市 Wheat Press」**= C 早市的版式骨架（小票日志/宋体标题/直角印刷感）× A 全麦的配色（面粉白画布 + 全麦棕主色）。用户原话："把 C 早市的配色搭配换成 A 全麦的就可以了"。以下 token 冻结。

### 形状与层次

- 圆角：输入 4px、按钮 6px、卡片 8px、徽章 2px、LED/圆点 1–2px（直角印刷倾向）
- 无阴影；唯一例外：小票 `0 6px 14px -10px rgba(27,27,24,.25)`（纸片浮在画布上）
- 边框 1px `--line`；分隔线在小票内用虚线（票据语言，编码"记录条目"信息）
- 锯齿边：小票顶部 8px 三角齿（SVG 平铺），颜色 = `--card`

### 版式骨架（自 C 早市，不变）

- 无边框窗口 + 自绘标题栏（印章 Logo + 宋体产品名 + 版本徽章 + 主题切换 + 窗口钮）
- 左：任务面板（下划线式 tab 切换模式，选中 = 全麦 2px 底线；表单直角输入；底部固定主操作条，主按钮宋体字距 4px）
- 右：小票日志控制台（锯齿顶边 + 等宽时间戳/级别 + 虚线分隔 + 命中价签黄高亮 + 页脚「— 一 口 轻 食 · 一 单 一 味 —」宋体小字）
- 朱砂角色全部由全麦棕接管；番茄红只做 danger。
